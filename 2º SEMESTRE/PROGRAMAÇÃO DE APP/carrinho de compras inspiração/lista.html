Exercício 1 — Carrinho de compras

Página pronta: index.html e css/estilo.css Seu arquivo: app.js Nome: ______________________________
Faça na ordem. Não altere o index.html nem o estilo.css — todo o trabalho é no app.js. Os preços e os nomes dos id já estão prontos para você. Abra o index.html no navegador e deixe o F12 aberto na aba Console. Salve com Ctrl+S e atualize o navegador a cada mudança.

Ligando o JavaScript na página

  1. Confirme que o app.js está sendo carregado: escreva um console.log("app.js carregado!") na primeira linha do arquivo e veja a mensagem aparecer no Console.
  2. Escreva o nome da loja dentro do <h1 id="nomeLoja"> usando textContent. Escolha o nome que quiser.
  3. Complete a função testar(), que já está ligada ao botão Testar conexão: ela deve escrever "JavaScript conectado!" dentro do #mensagem e também no Console. A caixa de mensagem começa escondida pela classe escondido. Ela só vai aparecer no exercício 15.

Lendo os campos do formulário

  1. Dentro da função calcular(), mostre no Console o .value do campo #qtd1 e também o typeof dele. Digite 2 no campo, clique em Calcular carrinho e observe o que aparece.
  2. Guarde as três quantidades (#qtd1, #qtd2, #qtd3) em variáveis, agora convertendo com Number(). Mostre o typeof de novo e compare com o exercício anterior.

As contas do carrinho

  1. Calcule o subtotal do Notebook (preço × quantidade) e escreva o resultado no #sub1, formatado com toFixed(2). Os preços já estão no topo do app.js: PRECO_NOTEBOOK, PRECO_MOUSE e PRECO_TECLADO.
  2. Faça o mesmo para o Mouse (#sub2) e para o Teclado (#sub3).
  3. Some os três subtotais e escreva o resultado no #subtotal do resumo.
  4. Some as três quantidades e escreva o resultado no #contadorItens, o número vermelho ao lado da sacolinha no topo da página.
  5. Escreva o valor do frete no #frete. Use a constante VALOR_FRETE que já existe no arquivo.
  6. Calcule o total (subtotal + frete) e escreva no #total.

O cupom de desconto

  1. Complete a função aplicarCupom(), ligada ao botão Aplicar: leia o código digitado em #cupom, calcule 10% de desconto sobre o subtotal, escreva o valor no #desconto e atualize o #total descontando esse valor. Por enquanto o cupom vale para qualquer código digitado. Conferir se o código está certo exige if — é exercício da aula 7.

Mexendo no CSS pelo JavaScript

  1. No fim da função calcular(), pinte o #total de verde usando .style.color.
  2. Ainda no #total, aumente a fonte com .style.fontSize e deixe em negrito com .style.fontWeight. No CSS é font-size, com hífen. No JavaScript vira fontSize, em camelCase. Vale para todas as propriedades.
  3. Faça a caixa #mensagem aparecer: use classList.remove("escondido") dentro da função testar() do exercício 3.
  4. Complete a função destacarPromocao(), ligada ao botão Destacar promoção: adicione a classe destaque ao #produto2 com classList.add. O CSS dessa classe já está pronto.
  5. Complete a função alternarTema(), ligada ao botão Tema escuro: use document.body.classList.toggle("tema-escuro"). Clique várias vezes e observe. toggle = se a classe não está, coloca; se está, tira. O tema escuro inteiro já está escrito no CSS.
  6. Faça a barra de frete grátis crescer: calcule quantos por cento o subtotal representa de FRETE_GRATIS_A_PARTIR_DE e aplique esse valor em .style.width do #barraFrete. A largura precisa do % no fim: "75" + "%". Se passar de 100% não tem problema agora — o CSS segura. Travar em 100% exige if, na aula 7.

Fechamento

  1. Complete a função limpar(), ligada ao botão Limpar carrinho: zere os quatro campos, zere todas as saídas e desfaça o que o JavaScript mexeu no CSS — tire o destaque do produto, volte a barra para 0% e esconda a mensagem de novo.
  2. Organize e entregue: comentários separando ENTRADA / PROCESSAMENTO / SAÍDA dentro de cada função, nomes de variáveis em camelCase e que digam o que guardam, arquivo formatado com Shift + Alt + F e commit no seu repositório.

Se sobrar tempo

  1. Troque a cor da barra de frete para laranja pelo JavaScript quando ela for preenchida.
  2. Faça o botão Destacar promoção também mudar o texto do #mensagem avisando qual produto está em promoção.
  3. Formate os valores no padrão brasileiro, com vírgula: valor.toLocaleString("pt-BR", { style: "currency", currency: "BRL" }) no lugar do toFixed(2).
  4. Acrescente um quarto produto no index.html, com o mesmo padrão de id, e inclua-o nas contas.

Comandos que você vai usar

document.getElementById("id") Pega um elemento da página pelo id
.value Lê o que está escrito num campo. Devolve sempre texto
Number(...) Converte texto em número, para poder fazer conta
.textContent = "..." Escreve um texto dentro de um elemento da página
.toFixed(2) Formata o número com duas casas decimais
.style.color = "green" Muda uma propriedade de CSS direto no elemento
.classList.add("nome") Coloca uma classe de CSS no elemento
.classList.remove("nome") Tira essa classe do elemento
.classList.toggle("nome") Coloca se não tem, tira se tem
console.log(...) Mostra um valor no Console, para você acompanhar
Travou? Abra o Console (F12). Se aparecer Cannot read properties of null, o id que você escreveu não existe na página — confira letra por letra. Se aparecer ... is not defined, o nome da função no onclick não bate com o nome no app.js. E se o resultado for NaN, faltou o Number() em algum campo.
